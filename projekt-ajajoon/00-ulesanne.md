# G3 Ajajoone projekt 2026 — ülesande tingimused

**Üldteema:** Elu raudse eesriide taga (ENSV aeg)
**Meie rühma teema (loositud):** Rahvuskultuuri säilitamise võimalused

## Kõvad piirid (neid ei tohi rikkuda)

| Tingimus | Väärtus |
|---|---|
| Pikkus | **2–3 minutit** (4–6 min = punktikaotus) |
| Formaat | **horisontaalne 16:9** — Shorts on keelatud |
| Esitamine | YouTube link, **Unlisted**, TEAMSi ülesande alla |
| Tähtaeg | **10.11** (mardipäev) |
| Rühm | 5 liiget |
| Allikad | **vähemalt 3**, usaldusväärsed ja (populaar)teaduslikud |
| Algus | sissejuhatav slaid |
| Lõpp | lõputiitrid: kõigi rühmaliikmete nimed · kasutatud näidete pealkirjad ja autorid · muusika autorid · **filmimispaik** · allikad |

## Hindamiskriteeriumid (mille peale stsenaarium ehitatakse)

1. **Seoste loomine viie aine vahel** — kirjandus, ajalugu, ühiskonnaõpetus,
   muusika, kunst. Kõrgeim hinne nõuab, et need on *omavahel tihedalt
   seotud ja loovad sisuka terviku*, mitte ei ole järjest loetletud.
   → Stsenaariumi nõue: iga aine peab olema **loo osa**, mitte lõik.
2. **Loovus ja originaalsus** — "hästi läbimõeldud loomingulised lahendused".
   → Nõue: üks kandev visuaalne või narratiivne võte läbi kogu video.
3. **Allikate usaldusväärsus, mitmekülgsus ja arv.**
   → Nõue: ≥5 allikat, eri tüüpi (arhiiv, teadustekst, audiovisuaalne).
4. **Sõnumi selgus, seostatus ja kaasahaaravus.**
   → Nõue: üks lause, mille vaataja pärast mäletab.
5. **Tehniline teostus meeskonnatööna** — monteerimine, heli, keeleline
   korrektsus. → Nõue: 5 rolli, igaühel oma vastutus.
6. **Kestus 2–3 min.** → Nõue: ~330–420 sõna kõneteksti, kontrollitud.

## Ainetunnid, mis selleks ette nähtud

## Autoriõiguse hoiatus (õpetaja kriteerium "kasutatud näited")
Iga arhiivikaader, foto ja helilõik vajab lõputiitrites autorit ja
pealkirja. Eelista: Rahvusarhiivi filmiarhiiv, ERR arhiiv, Eesti
Kirjandusmuuseum, Muis.ee — need on viidatavad. Kommertsmuusika
YouTube'is blokeerib video.
